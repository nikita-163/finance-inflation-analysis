# Анализ личных расходов с учётом инфляции

## О проекте

В рамках этого проекта анализируются личные расходы, их структура, динамика и возможная связь с инфляцией и ключевой ставкой Центрального Банка Российской Федерации. 

## Бизнес-задачи

В рамках проекта необходимо ответить на следующие вопросы:

- как менялись личные расходы в течение года?
- какие категории расходов занимают наибольшую долю бюджета?
- изменялся ли средний чек со временем?
- наблюдается ли сезонность в расходах?
- насколько рост расходов соответствует уровню инфляции?
- какой вклад в снижение фактических расходов вносит кэшбэк?

## Цели проекта

- Создать базу данных для хранения банковских операций.
- Импортировать банковскую выписку и данные по инфляции в PostgreSQL.
- Исследовать качество данных (EDA) с помощью SQL.
- Очистить и подготовить данные с помощью SQL.
- Проанализировать структуру и динамику личных расходов.
- Сопоставить изменение расходов с показателями инфляции.
- Выполнить дополнительный анализ с помощью Python + pandas.
- Визуализировать результаты в DataLens.
- Подготовить аналитический отчет с основными выводами.

## Этапы выполнения проекта

1. Создал свою базу данных personal_spending_and_inflation_data в PostgreSQL через DBeaver.
2. Создал в БД отдельную схему finance для будущих таблиц.
3. Спроектировал и создал 2 таблицы: bank_transactions с банковскими операциями и inflation с макроэкономическими показателями.
4. Импортировал 555 банковских операций и 12 периодов макропоказателей ЦБ.
5. Провел проверку корректности импорта (сверил с исходными файлами).
6. Выполнил исследовательский анализ данных (EDA) по 5 блокам: проверил в данных структуру, полноту, уникальность, распределения/аномалии и согласованность бизнес-логики. Нашёл и обосновал несовпадение временных диапазонов между таблицами.
7. Очистил и подготовил данные с помощью SQL: определил набор столбцов и правила фильтрации реальных расходов, создал представление v_real_expenses.
8. Выполнил SQL-анализ по всем бизнес-вопросам: динамика расходов, доля категорий, средний чек, сезонность, сопоставление с инфляцией, вклад кэшбэка.

## Источники данных

В проекте используются два набора данных:

- личная банковская выписка (около 555 операций);
- ежемесячные данные Банка России по инфляции и ключевой ставке.

Примечание: исходная банковская выписка не размещается в репозитории, поскольку содержит персональные финансовые данные.

## Основные выводы

Итоговые выводы будут добавлены после завершения основного анализа. Промежуточный итог по результатам EDA:

- Структура. Обе таблицы имеют ожидаемую структуру и типы данных.
- Полнота. NULL в критичных полях не выявлены, пропущенных месяцев/периодов нет в пределах имеющихся диапазонов.
- Уникальность. Технических дублей от повторного импорта не обнаружено. Справочные значения согласованы, вариаций в написании не найдено.
- Распределение и аномалии. Аномалий не выявлено.
- Согласованность бизнес-логики. Значения в критических полях логически непротиворечивы.

Промежуточный итог по результатам SQL-анализа:

- Динамика изменения личных расходов. Общая сумма расходов по месяцам стабильна. Отклонение от средней суммы трат по месяцам не превышает 17% в обе стороны.
- Доля категорий в расходах. Топ 5 категорий расходов (продукты, фастфуд, переводы другим людям, прочие расходы, медицинские услуги) занимают 93% всех расходов, что говорит о высокой концентрации трат в этих 5 категориях.
- Динамика изменения среднего чека. Высокое колебание среднего чека (от -24% до +97% от среднего по месяцам) объясняется наличием месяцев с большим количеством мелких трат и месяцев с маленьким количеством крупных тарт.
- Сезонность расходов. Расчёт с учётом фактического числа месяцев в каждом квартале выявил, что 51,7% трат приходится на третий квартал, что говорит о наличии сезонности в расходах.
- Реальный рост расходов относительно инфляции. Реальные расходы выросли значительно быстрее инфляции (в 2,03 раза), такой рост связан с удорожанием товаров и услуг и изменением объёма и структуры трат.
- Вклад кешбэка в снижении расходов. Кешбэк с покупок покрывает 4% фактических расходов. В будущем стоит рассмотреть возможность увеличения получаемого кешбэка.
